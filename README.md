## ✨ Overview

This portfolio website represents my journey as a Full Stack Developer, Data Scientist, Machine Learning Engineer, and AI Enthusiast.

⚙️ Getting Started
1. Clone the repository
git clone https://github.com/sheiknuman287/portfolio-website.git
2. Navigate to the project
cd portfolio-website
3. Install dependencies
npm install
4. Start the development server
npm run dev

The application will then be available through the local development URL provided by Vite.

🏗️ Build for Production

To create a production build:

npm run build

To preview the production build locally:

npm run preview
🚀 Deployment

The portfolio is deployed using Vercel and connected directly to the GitHub repository.

Every update pushed to the main branch can be deployed through the connected Vercel project.
